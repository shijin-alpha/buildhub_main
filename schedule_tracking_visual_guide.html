📅 Schedule Tracking Visual Guide

Understanding Planned vs Actual Schedule Management

🔄 Complete Workflow

1

Project Approval

Project created and approved. All schedule fields are NULL.

2

Set Planned Dates

Contractor sets planned start and end dates.

3

Record Actual Start

Work begins. Planned dates lock automatically.

4

Complete Project

Record actual end. Overrun calculated automatically.

📊 Project Timeline Visualization

Phase 1: Planning

Contractor Action: Set planned_start_date = Feb 1, 2026

Contractor Action: Set planned_end_date = May 1, 2026

System: Planned duration = 90 days

Status: Dates can still be modified

Phase 2: Project Start

Contractor Action: Record actual_start_date = Feb 5, 2026

System: Set planned_dates_locked = 1

Status: Planned dates now immutable

Note: Started 4 days late

Phase 3: Project Completion

Contractor Action: Record actual_end_date = May 15, 2026

System: Calculate actual duration = 100 days

System: Calculate overrun = ((100-90)/90) × 100 = +11.11%

System: Calculate delay = 14 days

Status: Project completed (delayed)

🧮 Calculation Formulas

Time Overrun Percentage

((actual_duration - planned_duration) / planned_duration) × 100

Positive = Delayed | Negative = Early | Zero = On Time

Delay in Days

actual_end_date - planned_end_date

Positive = Late | Negative = Early | Zero = On Time

📈 Real-World Examples

Example 1: Delayed Project

👥 Role-Based Permissions

👷 Contractor

  • Set planned start and end dates
  • Modify planned dates (before actual start)
  • Record actual start date
  • Record actual end date
  • View all schedule data
  • View audit logs

🏠 Homeowner

  • View planned schedule (read-only)
  • View actual dates (read-only)
  • View time overrun percentage
  • View delay information
  • Cannot modify any dates
  • Receive schedule updates

⚙️ Admin

  • View all project schedules
  • Override actual end dates
  • Access complete audit trails
  • Generate schedule reports
  • Monitor time overruns
  • System-wide analytics
