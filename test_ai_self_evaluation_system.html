How It Works

  • Predictions are saved when homeowner confirms project
  • Predictions lock automatically when work begins
  • Projects are evaluated automatically on completion
  • Metrics are calculated using confusion matrix
  • All changes are backward compatible

Classification Logic

  • TP: Predicted High/Med + Actual Overrun
  • FP: Predicted High/Med + No Overrun
  • TN: Predicted Low + No Overrun
  • FN: Predicted Low + Actual Overrun
