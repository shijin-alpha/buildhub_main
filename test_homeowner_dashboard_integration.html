🔧 API Endpoint

Endpoint: /buildhub/backend/api/homeowner/get_dashboard_data.php

Method: GET

Authentication: Session-based (credentials: 'include')

📋 Usage Instructions

  1. Login as Homeowner: Use the existing login system to authenticate as a homeowner
  2. Navigate to Dashboard: Click on the dashboard tab in the homeowner interface
  3. View Progress: The Progress Overview widget will show active construction projects
  4. Track Budget: The Budget Tracker widget will display payment information and budget utilization
  5. Refresh Data: Click the refresh button (↻) to reload dashboard data
  6. View Details: Click the view details button (👁️) for budget summary
