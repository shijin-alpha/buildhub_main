🚀 How to Use

  1. Login as Contractor and navigate to Progress Updates
  2. Click "📁 Stage Documents" in the toggle buttons
  3. Select a Project from the dropdown (auto-selects first project)
  4. Upload Documents:
    • Choose construction stage (Foundation, Structure, etc.)
    • Select document type (Receipt, Bill, Invoice, etc.)
    • Add description
    • Drag-and-drop or browse files
    • Click upload
  5. View Documents: Browse uploaded documents by stage and type
  6. Track Progress: Monitor completion statistics and verification status
