Simple Receipt Upload System

No payment logic - just upload receipts and view them

🎯 System Overview

What This System Does

This is a simple receipt upload system where contractors can upload any receipt and both contractors and homeowners can view them in a documents section. No complex payment logic - just basic file upload and viewing.

  • Contractors upload any receipt with title and description
  • Both contractor and homeowner can view all uploaded receipts
  • Support for images (JPG, PNG) and PDF files
  • Simple file management with download capability
  • Clean, responsive interface
  • No payment processing or verification logic

🗄️ Database Setup

CREATE TABLE simple_receipts ( id, project_id, contractor_id, homeowner_id, receipt_title, description, file_path, original_filename, file_size, mime_type, upload_date )

📤 Upload System

POST /buildhub/backend/api/contractor/upload_simple_receipt.php

Upload Features

Contractors can upload receipts with a title, optional description, and file. Supports drag-and-drop, file validation, and progress feedback.

👀 Viewing System

GET /buildhub/backend/api/get_simple_receipts.php?project_id=X

Viewing Features

Both contractors and homeowners can view all receipts for a project. Images open in a modal, PDFs open in new tab, and all files can be downloaded.

🧩 React Components

  • SimpleReceiptUpload.jsx - Upload modal with drag-and-drop
  • SimpleReceiptViewer.jsx - Grid view of all receipts
  • SimpleReceiptManager.jsx - Combined upload + viewing interface

🚀 Integration Guide

How to Use

1. Run the database setup script
2. Import SimpleReceiptManager component
3. Pass projectId and userRole props
4. Component handles everything else automatically

import SimpleReceiptManager from './components/SimpleReceiptManager.jsx'; <SimpleReceiptManager projectId={projectId} userRole="contractor" // or "homeowner" />
