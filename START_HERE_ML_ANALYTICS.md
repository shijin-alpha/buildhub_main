# 🚀 START HERE - ML Analytics Dashboard

## ⚡ Quick Start (2 Steps)

### Step 1: Run Database Setup (1 minute)

Open this file in your browser:
```
http://localhost/buildhub/setup_ml_analytics.html
```

Click the "🚀 Run Setup" button and wait for success message.

### Step 2: Use the Dashboard

1. Login as **Contractor** or **Admin**
2. Click **"🤖 ML Analytics"** in the sidebar
3. Select a project from dropdown
4. **Done!** View your charts and insights
