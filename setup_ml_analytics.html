🤖 ML Analytics Dashboard Setup

Set up the required database tables for the ML Analytics Dashboard

📋 What This Does

This setup will:

  • Create ai_predictions table for storing ML predictions
  • Create ai_evaluation_metrics table for model performance
  • Insert sample predictions for your existing projects
  • Insert model performance metrics (94.7% and 98.9% accuracy)

Step 1: Run Database Setup

Click the button below to create the required tables and insert sample data.

Step 2: Test the API

After setup, test if the API is working correctly.

Step 3: View Dashboard

Once everything is set up, you can access the ML Analytics Dashboard.

⚠️ Troubleshooting

If you see errors:

  • Make sure your database is running (MySQL/MariaDB)
  • Check database connection in backend/config/database.php
  • Ensure your database user has CREATE TABLE permissions
  • If tables already exist, that's OK - the setup is idempotent
